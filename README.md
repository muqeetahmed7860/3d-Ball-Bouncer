# 3D Ball Bouncer

A simple 3D ball bouncing game developed in Unity using C#. The project demonstrates core game development concepts including physics-based movement, collision detection, player controls, and object interactions.

## Features

* 3D gameplay environment
* Physics-based ball movement
* Collision detection system
* Interactive game objects
* Simple and responsive controls

## Technologies Used

* Unity Engine
* C#
* Unity Physics System

## Project Purpose

This project was developed to strengthen my understanding of Unity game development fundamentals, including game mechanics, scripting, and physics-based interactions.

## How to Run

1. Clone this repository.
2. Open the project in Unity.
3. Load the main scene.
4. Press Play in the Unity Editor.

## Learning Outcomes

Through this project, I gained practical experience with:

* Unity Game Objects
* Rigidbody Physics
* Collision Handling
* Scene Management
* C# Scripting
